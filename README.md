# 제주 안심길

**교통사고 데이터 AI 도우미.** 제주데이터허브의 교통사고 공개 데이터를 도민이 쉬운 말로 물어보고, **근거와 한계까지 함께** 답을 받는 서비스입니다.

> "비 오는 날 사고가 더 위험한가요?" → 데이터를 찾아 계산하고, 차트·지도와 함께 설명하되 *"교통량을 반영하지 않은 비교"* 같은 한계를 빠뜨리지 않습니다.

---

## 무엇을 할 수 있나요

| 기능 | 설명 |
|---|---|
| **질문하기** | 한국어로 묻기만 하면 알맞은 분석을 골라 실행하고 차트·표·지도로 보여 줍니다. 왼쪽에 질문 기록이 남고, 누르면 다시 질문합니다. 왼쪽 메뉴의 '질문하기'를 누르면 예시 질문이 있는 시작 화면으로 돌아갑니다. |
| **자동 점검 보고서** | 버튼 한 번으로 전체 데이터를 분석해 핵심 발견·요인별 분석·보행자 사고·전망·한계를 정리합니다. HTML(인터넷 없이 열림, PDF 저장 가능)과 Markdown으로 내려받습니다. |
| **데이터 현황** | 어떤 데이터를 쓰는지, 자동 점검에서 발견한 문제와 **반영한 조치**를 보여 줍니다. |
| **도로선형·교차로 그림** | 직선·커브·오르막·내리막, 삼지·사지·회전교차로 등을 도로 모양 그림과 사고 수치 카드로 표현합니다. |
| **사고 지점 지도** | 보행자 사고가 실제로 몰린 지점과 사고 다발지역을 지도에 원으로 표시합니다. |
| **편의 기능** | 왼쪽 메뉴(질문하기 / 자동 점검 보고서 / 데이터 현황)·AI 설정·질문 기록, 오른쪽 아래 위/아래 이동 버튼, 화면이 나타날 때의 부드러운 움직임과 버튼 눌림 효과(anime.js, '움직임 줄이기' 설정 존중), 차트는 둥근 막대·부드러운 곡선·카드형 말풍선(Bklit 풍), 분석 중에는 신호등 색 점 로딩 표시 |
| **월별 전망** | 향후 최대 12개월 전망을 80% 범위와 **검증 오차**와 함께 보여 줍니다. 오차가 너무 크면 전망을 제공하지 않습니다. |
| **개선 제안** | (자동 점검 보고서 6절과 질문 "교통사고를 줄이려면?"에서 제공) 분석 결과를 근거로 **도민 행동 안내**와 **담당 기관 검토 제안**을 만듭니다. 제안마다 근거 수치·한계·근거 강도(표본 크기 기준)를 붙이고, 우선 점검 지점은 지도로 보여 줍니다. |

## 설계 원칙

1. **숫자는 코드가 계산하고, AI는 설명만 합니다.** 모든 수치는 SQL/pandas가 계산합니다. AI는 질문 해석과 설명 문장에만 쓰입니다(권장: OpenRouter 경유 Claude Haiku 5.5. 외부 전송이 불가하면 로컬 Ollama, 단 평가에서 기준 미달).
2. **지어낸 숫자를 막습니다.** AI가 쓴 문장에 분석 결과에 없는 숫자가 있으면 그 문장만 제외하고, 주의사항(※)은 코드가 정확한 원문으로 덧붙입니다.
3. **한계를 숨기지 않습니다.** 모든 답변에 "교통량 미반영", 표본 부족, 전망의 가정 등을 표시합니다.
4. **의심스러운 데이터는 스스로 찾아냅니다.** 예: 기상 파일의 2005~2015년이 전국 규모 값으로 의심되어 자동 제외됩니다(`suspect` 표시).
5. **AI가 꺼져 있어도 동작합니다.** 키워드 규칙으로 분석 도구를 고르고 계산된 요약문을 그대로 보여 줍니다.
6. **보내는 것을 최소로 하고, 보관·학습을 막습니다.** 질문 기록은 이 PC의 `data/history.json`에만 저장됩니다. 외부 AI를 쓰면 **질문 문장과 계산된 결과 요약만** 전송하고(원자료·개인정보 없음), OpenRouter 요청에 "저장·학습 금지 + 데이터 무보관(ZDR) 제공자만" 조건을 기본으로 붙입니다. 외부 전송 자체가 불가한 환경은 로컬 Ollama를 쓰세요.

## 빠른 시작

```bash
pip install -r requirements.txt

# 1) 데이터 수집·정리 (reference/ 폴더의 CSV + 다발지역 API)
python -m jeju_traffic.collect

# 2) 앱 실행
streamlit run app.py          # 또는: python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열립니다.

### AI 해설 켜기 (선택)

**권장: OpenRouter + Claude Haiku 5.5** — 키만 넣으면 됩니다(`.env`의 `OPENROUTER_API_KEY=...`, 또는 화면 왼쪽 **AI 설정**에 입력). 같은 20문항 평가에서 도구 선택 94~100%, 숫자 충실도 100%, 응답 약 5~6초였습니다(아래 '모델 검증').

- 전송되는 것: 질문 문장, 계산된 결과 요약. 보내지 않는 것: 원자료, 개인정보.
- 기본으로 `data_collection=deny`(저장·학습 금지)와 `zdr=true`(데이터 무보관 제공자만)를 붙이며, 이 조건에서 Claude Haiku 5.5는 Amazon Bedrock으로 처리됩니다. `LLM_PROVIDER_ONLY`로 제공자를 고정할 수 있고(예: `azure`는 무보관 조건과 함께 쓸 수 없었음), `LLM_PRIVACY=off`로 끌 수 있습니다(권장 안 함).
- 이 조건은 OpenRouter가 분류한 정책이며 법적 보증이 아닙니다. 기관 보안 심의가 필요하면 제공자 약관·계약을 확인하세요.
- OpenAI·Anthropic 키를 직접 쓰려면 `OPENAI_API_KEY`·`ANTHROPIC_API_KEY`(이 경로에는 위 OpenRouter 개인정보 옵션이 적용되지 않으므로 계약 조건을 따로 확인).

**외부 전송이 불가한 경우(선택·실험): 로컬 Ollama** — 화면 'AI 설정'에서 "로컬 Ollama"를 고르고 모델 이름을 입력합니다. 평가한 `gemma3:4b`·`gpt-oss:20b`는 정확도가 기준에 못 미쳤고, 더 큰 모델은 시험하지 않았습니다.

```bash
winget install Ollama.Ollama      # 설치 후 터미널을 새로 여세요
ollama pull gemma3:4b             # 약 3.3GB
```

사이드바에 "AI 연결됨"과 모델 이름이 뜨면 켜진 것입니다. 모델은 화면의 '모델 이름' 또는 환경변수 `OLLAMA_MODEL`로 바꿀 수 있습니다(`ollama list`로 설치된 이름 확인).

> **속도 안내:** 그래픽카드가 없는 PC(CPU만)에서는 답변마다 1~2분 걸릴 수 있습니다(측정: 40~150초). GPU가 있으면 훨씬 빠릅니다. 이때도 분석 결과(차트·표)는 AI와 무관하게 즉시 계산됩니다.

### 설정 (`.env`, 모두 선택)

`.env.example`을 복사해 `.env`로 쓰세요.

| 변수 | 설명 |
|---|---|
| `TRAFFIC_HOTSPOT_URL` | 데이터허브 "교통사고 다발지역" API 주소(키 포함). 공개 저장소에 올리지 마세요. |
| `GOOGLE_MAPS_API_KEY` | 있으면 구글 지도, 없으면 OpenStreetMap 지도로 표시됩니다. |
| `LLM_PROVIDER`, `LLM_MODEL` | AI 서비스(`openrouter` 기본 / `openai` / `anthropic` / `ollama`)와 모델 이름. 키만 설정하면 해당 서비스가 자동 선택됩니다. 화면 왼쪽 **AI 설정**에서도 고를 수 있습니다. |
| `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` | 외부 AI 서비스 키. **외부 서비스를 쓰면 질문과 분석 결과 요약이 외부로 전송됩니다**(원자료·개인정보는 보내지 않음). 화면에서 입력한 키는 메모리에만 보관합니다. |
| `OLLAMA_MODEL`, `OLLAMA_URL` | 사용할 AI 모델과 주소(기본 `gemma3:4b`, `http://127.0.0.1:11434` — Windows에서 `localhost`는 이름 해석에 약 2초 걸려 IP로 접속합니다). |
| `TRAFFIC_RAW_DIR` | 원천 CSV 폴더(기본 `reference/`). |
| `TRAFFIC_HOTSPOT_PERIOD` | 다발지역 자료의 제공 기간 문구(기본 `2017~2023년`). |

## 센터 PC 설치·실행 절차

대상: Windows, Intel Core i7-8700 / GTX 1060 / RAM 32GB. 인터넷이 막힌 PC라면 ②·③의 파일을 다른 PC에서 받아 반입하세요.

| 순서 | 할 일 | 비고 |
|---|---|---|
| ① | Python 3.12 설치 | 개발·검증 환경(3.12.10). 설치 시 "Add to PATH" 체크 |
| ② | 프로젝트 폴더에서 `pip install -r requirements.txt` | 오프라인: 다른 PC에서 `pip download -r requirements.txt -d wheels` 후 `pip install --no-index --find-links wheels -r requirements.txt` |
| ③ | AI 서비스 선택: OpenRouter 키를 `.env`에 입력(권장) 또는 Ollama 설치 후 `ollama pull gemma3:4b`(약 3.3GB) | 외부 전송 불가 시 Ollama. 오프라인 반입: 모델 폴더(`%USERPROFILE%\.ollama\models`)를 통째로 복사. 센터에서 외부 인터넷(openrouter.ai) 접속이 허용되어야 외부 AI 사용 가능 |
| ④ | `.env.example`을 `.env`로 복사 | 다발지역 API 주소를 쓸 때만 필요. 자료가 이미 `data/`에 있으면 생략 가능 |
| ⑤ | `python -m jeju_traffic.collect` | 새 CSV를 `reference/`에 넣었을 때만(기존 `data/jeju_traffic.sqlite` 사용 시 생략) |
| ⑥ | `streamlit run app.py` → 브라우저 `http://127.0.0.1:8501` | 사이드바에 "AI 연결됨"이 뜨면 정상(키가 없으면 "기본 분석 모드") |
| ⑦ | (선택) `python -m jeju_traffic.evaluate` | 센터 PC에서 모델 정확도·속도 측정 |

**최신 자료로 바꾸려면:** 새 CSV를 `reference/`에 넣고 ⑤를 실행한 뒤 앱을 다시 시작합니다. 화면의 연도는 데이터에서 읽어 자동으로 바뀝니다. 새 파일의 열 구성이 기존과 다르면 `jeju_traffic/sources.py`의 파서 수정이 필요합니다.

**외부 연결:** 분석·차트·보고서·기본 분석 모드는 인터넷 없이 동작합니다. 인터넷이 쓰이는 곳은 ① AI 설명(외부 AI 서비스를 쓸 때: openrouter.ai 등), ② 지도 배경 타일(OpenStreetMap), ③ 글꼴(Google Fonts, 실패 시 기본 글꼴), ④ 다발지역 API 수집, ⑤ 구글 지도(키 설정 시)입니다. 화면 움직임(anime.js)은 파일이 내장되어 있어 인터넷이 필요 없습니다.

## 사용자 매뉴얼 (도민용)

1. **브라우저에서 주소를 엽니다.** 화면 왼쪽에 메뉴(질문하기 / 자동 점검 보고서 / 데이터 현황), AI 설정, 질문 기록이 있고 오른쪽에 내용이 나옵니다. '질문하기'를 누르면 예시가 있는 시작 화면으로 돌아갑니다.
2. **질문하기:** 아래 입력창에 궁금한 것을 쓰거나 "이런 걸 물어볼 수 있어요"의 예시를 누릅니다. 예) "비 오는 날 사고가 더 위험한가요?", "보행자 사고가 많이 난 곳을 지도로 보여줘", "앞으로 1년 전체 사고를 전망해줘".
3. **답변 읽기:** 위에서부터 설명 문장 → ※ 한계 → 차트·지도·표입니다. "표 보기"를 누르면 원자료 표가 열립니다. 연도는 질문에 쓰지 않아도 됩니다(자료가 있는 기간 전체를 씁니다. 없는 연도를 물으면 보유 기간을 안내합니다).
4. **지도:** 오른쪽 목록의 이름을 누르거나 지도의 숫자를 누르면 그 지점으로 확대되고 사고 건수·사망·중상·주된 법규위반이 말풍선으로 뜹니다. "전체 보기"로 되돌립니다.
5. **연결 호출(다단계):** 분석과 대책을 함께 묻는 질문("어린이 사고 줄이려면?", "노인 사고 추이랑 어디서 많이 나는지")은 분석 도구를 먼저 부르고 개선 제안·다발 지점을 이어서 부릅니다(최대 2단계). 답변 아래 "분석 단계 1. … → 2. …"로 순서가 표시됩니다.
6. **개선 제안:** 자동 점검 보고서의 '개선 제안' 절과 질문("교통사고를 줄이려면?")에서 볼 수 있습니다. "도민"(바로 실천할 안전 수칙)과 "담당 기관"(점검 사항)으로 나뉩니다. 칩의 **근거 강함/보통/약함**은 표본 크기 기준이며, 제안은 원인이나 효과를 증명하지 않는 검토 의견입니다.
7. **자동 점검 보고서:** 저장된 보고서가 먼저 보입니다. 자료를 바꾼 뒤에는 "보고서 다시 만들기"를 누르고, HTML(인터넷 없이 열림)·Markdown으로 내려받습니다.
8. **데이터 현황:** 사용 자료의 기간·규모와 자동 점검 결과(신뢰도)를 봅니다.
9. **AI 해설 켜기/끄기·AI 설정:** 왼쪽 스위치로 켜고 끕니다. 끄거나 키가 없으면 계산된 요약문을 즉시 보여 주고, 켜면 쉬운 설명이 덧붙습니다(외부 AI 약 5초, 로컬 모델은 CPU만 있는 PC에서 약 30초~2분). 'AI 설정'에서 서비스(OpenRouter / OpenAI / Anthropic / 로컬 Ollama)·모델 이름·API 키를 고릅니다. 키는 화면을 여는 동안 메모리에만 보관되고 파일에 저장되지 않습니다. AI 호출이 실패하면 답변 아래에 이유(예: `401 API 키가 올바르지 않아요`)가 표시되고 기본 분석으로 답합니다.
10. **위/아래 이동:** 화면이 길면 오른쪽 아래의 동그란 버튼으로 맨 위·맨 아래로 이동합니다.
11. **질문 기록 지우기:** 사이드바 맨 아래 "기록 지우기".

## 알려진 한계

- **자료 기간이 표마다 다릅니다.** 요인을 겹쳐 보는 분석은 사고 단위 자료인 **보행자 사고**(2018~2019)에서만 가능합니다. 나머지는 요인별로 따로 집계된 표입니다.
- **사고 건수는 위험도가 아닙니다.** 교통량·보행량이 없어 "건수가 많다 ≠ 더 위험하다"입니다. 표본이 30건 미만인 구분은 치명도가 크게 흔들립니다.
- **전망은 참고용입니다.** "계절 패턴과 최근 12개월 수준이 이어진다"는 가정이라 증가·감소 추세는 반영하지 않습니다. 검증 오차가 35%를 넘으면(예: 단속 건수) 전망하지 않습니다.
- **AI 설명은 보조입니다.** 모델이 도구를 잘못 고르거나 숫자를 지어낼 수 있어(소형 모델일수록), 분명한 질문은 규칙이 도구를 고르고 AI는 설명만 맡습니다. 근거 없는 숫자가 든 문장, '지도를 보여드릴 수 없다'처럼 화면과 맞지 않는 문장, 중간에 끊긴 문장은 자동으로 빠집니다. 규칙이 판단하지 못하는 범위 밖 질문(예: "지금 도로 상황")은 AI가 엉뚱한 도구를 고를 수 있습니다.
- **다발지역 API는 연도 정보가 없습니다.** 7개 시점의 도시별 상위 3곳 순위표를 합친 형태라 "순위표에 몇 번 올랐는가"로만 분석합니다.

- **개선 제안은 '검토 의견'입니다.** 통계는 원인과 개선 효과를 증명하지 않고, 교통량·보행량이 없으며, 이미 시행 중인 정책을 알 수 없습니다. 근거 강도는 표본 크기(사고 300건 이상=강함, 100건 이상=보통, 미만=약함)로 정하고 요인 비교형 제안은 최대 '보통'으로 제한합니다. 현장 조사와 전문가 검토가 필요합니다.

## 오류·제약사항 요약

- 로컬 Gemma 3 4B는 평가에서 **부적합**(도구 선택 67%, 숫자 충실도 0%, 응답 약 80초, CPU 전용 PC)이었습니다. 로컬 `gpt-oss:20b`도 도구 선택에 실패해 쓰지 않습니다. 센터 PC(GTX 1060)의 로컬 성능은 측정하지 못했습니다.
- 외부 AI는 인터넷(openrouter.ai) 연결과 API 키, 사용 비용이 필요합니다. 외부 서비스가 막히면 키가 없을 때와 같이 규칙 기반 기본 분석 모드로 답합니다.
- 지도 배경과 글꼴은 인터넷이 막히면 나오지 않습니다(지점 목록·표·차트는 정상).
- 다발지역 API는 일일 호출 한도가 있고, 키가 없으면 해당 자료만 빠집니다(나머지 기능은 동작).
- 원천 CSV의 열 구성이 바뀌면 파서(`sources.py`) 수정이 필요합니다.
- 여러 명이 동시에 쓰는 상황은 시험하지 않았습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "DB가 없습니다" | `python -m jeju_traffic.collect`를 먼저 실행 |
| 다발지역 API가 403 | 데이터허브 호출 한도(일일 쿼터)일 수 있습니다. 하루 뒤 다시 실행하세요(이어받기 지원). |
| "API 키가 없어 기본 분석 모드" | 왼쪽 'AI 설정'에 키를 입력하거나 `.env`에 `OPENROUTER_API_KEY` 설정 |
| "AI 호출에 실패해(401 …)" | 이유가 괄호 안에 나옵니다. 401=키 오류(서비스와 키 종류가 맞는지 확인: `sk-or-…`는 OpenRouter), 402=크레딧 부족, 403(한도)=키 사용 한도 초과, 404=모델 이름 오류 또는 저장·학습 금지 조건을 만족하는 제공자가 없는 모델, 429=잠시 뒤 재시도 |
| "AI 모델(Ollama)이 꺼져 있어…" | Ollama 설치·실행 후 `ollama pull <모델>`(로컬 Ollama를 고른 경우만) |
| 지도가 안 나옴 | 지도 타일은 인터넷 연결이 필요합니다. 구글 지도는 키·결제·웹사이트 제한 설정도 확인하세요. |
| 수정한 코드·스타일이 안 보임 | 실행 중인 앱은 이전 모듈을 기억합니다. `Ctrl+C` 후 `streamlit run app.py`로 다시 켜고 브라우저에서 `Ctrl+F5`. |
